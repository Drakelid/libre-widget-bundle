| Widget                                        | What it would show                                                                                                      | Why it is useful                                                               |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **Network Impact Overview**                   | Current failures grouped by site/device/uplink, estimated downstream devices/interfaces/customers affected              | Turns 30 individual alerts into one understandable incident                    |
| **Customer / Partner Impact**                 | Which customers, partners, sites or device groups are affected by a failure                                             | Lets the NOC immediately answer “who is affected?”                             |
| **Capacity Risk / Forecast**                  | Interfaces approaching 70/80/90% utilization, 95th percentile, growth rate, estimated date of saturation                | Helps identify upgrades before congestion happens                              |
| **Interface Errors & Discards**               | Interfaces with highest CRC errors, input/output errors, drops and discards, with rate of change                        | Finds bad optics, fibers, duplex issues and congestion before links go down    |
| **Latency / Packet Loss Hotspots**            | Devices/sites with increasing latency, packet loss or jitter                                                            | Catches degraded services that are technically still “up”                      |
| **Redundancy Risk / Single Point of Failure** | Sites where one uplink, LAG member, PSU, BGP peer or redundant device is already unavailable                            | Extremely valuable because the next failure becomes an outage                  |
| **Optical Degradation / Margin**              | RX/TX power relative to warning thresholds and historical trend rather than just current optical levels                 | Identifies dirty connectors, failing optics and degrading fiber before failure |
| **Monitoring Coverage Audit**                 | Devices missing alert policies, coordinates, groups, descriptions, sensors, OS detection, dependencies, SNMP data, etc. | Keeps LibreNMS itself healthy as the network grows                             |
| **Active Incident Summary**                   | Number of incidents by severity, duration, device group and probable root cause                                         | Better NOC overview than simply counting alerts                                |
| **Alert Storm / Noise Monitor**               | Devices/interfaces producing unusually large numbers of alerts over 5m/1h/24h                                           | Helps detect both network instability and badly configured alert policies      |
| **Maintenance / Suppression Overview**        | Devices currently in maintenance, upcoming maintenance windows and accidentally long-running suppressions               | Prevents hidden failures and forgotten maintenance states                      |
| **Device Resource Pressure**                  | Highest CPU, RAM, storage, process/load and temperature pressure, preferably combined into a score                      | Finds routers/switches approaching resource exhaustion                         |
| **Routing Instability**                       | BGP/OSPF/ISIS neighbor changes, prefix-count changes, route flapping and sessions repeatedly resetting                  | Goes beyond the binary BGP Session Health widget                               |
| **Site Health Score**                         | One score per site based on device state, uplinks, optics, power, temperature, packet loss and alarms                   | Very effective for quickly spotting problematic sites                          |
| **Network Availability Heatmap**              | Availability % by device group/site for 24h/7d/30d                                                                      | Gives management and NOC teams a simple view of persistent problem areas       |
| **Weather / Infrastructure Risk Map**         | Sites overlaid with wind, lightning, extreme temperature, precipitation or power-risk information                       | Particularly useful for geographically distributed infrastructure              |
| **Recent Network Changes**                    | Recently changed firmware, interface status/configuration, device replacements, IP changes, neighbor changes            | Useful when determining “what changed before the outage?”                      |
| **Firmware / Lifecycle Overview**             | OS versions, old firmware, unsupported hardware models and inconsistent versions                                        | Helps standardize the fleet and plan replacements                              |
| **Dependency / Downstream Health**            | Device → uplink → aggregation → core relationships with affected downstream nodes                                       | Enables rudimentary root-cause analysis                                        |
| **Link Headroom**                             | Current / peak / 95th percentile utilization and remaining Mbps/Gbps for important links                                | More operationally useful than utilization percentage alone                    |
